# UAE Stock Agent — GitHub Pages

وكيل عربي بسيط لعرض وتحليل مجموعة من أسهم سوق أبوظبي وسوق دبي.

## لا يحتاج Node.js
التطبيق صفحة ثابتة، وتحديث البيانات يتم داخل GitHub Actions باستخدام Python.

## تشغيل التحديث
1. افتح المستودع.
2. افتح تبويب **Actions**.
3. اختر **Update UAE market data**.
4. اضغط **Run workflow**.
5. انتظر حتى تظهر علامة النجاح الخضراء.

## نشر الموقع
1. افتح **Settings** داخل المستودع.
2. اختر **Pages**.
3. تحت **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. اضغط **Save**.
5. انتظر دقيقتين تقريباً ثم افتح رابط GitHub Pages الظاهر.

## ملاحظات مهمة
- التحديث المجدول يعمل من الأحد إلى الخميس قرابة 4:45 مساءً بتوقيت الإمارات.
- المصدر yfinance/Yahoo Finance غير رسمي وقد تكون البيانات متأخرة أو ناقصة.
- بعض رموز الشركات قد تتغير أو لا تكون مدعومة.
- القيم العادلة والتوصيات تقديرية وليست أوامر شراء أو بيع.
